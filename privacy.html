Privacy Policy

Root Cause and Root Cause Publisher · Effective 9 November 2026

Short version: this website collects nothing. Root Cause Publisher only touches the channel owner's own YouTube account, keeps its data on the owner's own computer, and shares it with no one.

1. Who we are

Root Cause is a YouTube channel run by Ahsen Serkan Usta, Germany (the "operator"). Contact: ahseust@gmail.com. This policy covers this website and the desktop tool Root Cause Publisher.

2. This website

This website uses no cookies, analytics, trackers, ads or forms. It stores nothing in your browser. The hosting provider may keep standard server logs (such as IP address and time of request) for security; see the host's own privacy policy.

3. Root Cause Publisher

Root Cause Publisher is a private desktop script that runs on the operator's own computer. Only the operator signs in to it, with the Google account that owns the Root Cause channel. It uses YouTube API Services.

Google permission (scope)What it is used for
youtube.uploadUpload the channel's own video files and set their title, description, schedule and privacy status.
youtubeRead the channel's own list of uploaded video titles (to avoid duplicate uploads), set thumbnails, and create and fill the channel's playlists.

Data it handles: the channel name and ID, the titles and IDs of the channel's own videos, and the OAuth sign-in token.

Where it is stored: only on the operator's computer, in two local files: token.json (the sign-in token) and publish_log.json (which files were uploaded, their video IDs, titles and file checksums). Nothing is sent to any server other than Google's YouTube API.

What it does not do: it does not read viewer data, comments, subscribers, messages, analytics or any other person's account. It does not sell, share, or transfer data to anyone, and does not use it for advertising or to train AI models.

4. Google API Services User Data Policy

Root Cause Publisher's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

By using YouTube API Services through this tool, users are bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

5. Keeping and deleting data

Local data is kept as long as the operator uses the tool. Deleting token.json and publish_log.json removes it. Access can be revoked at any time on the Google security settings page; YouTube API data stored by the tool is deleted or refreshed within 30 days, as YouTube's developer policies require.

6. YouTube viewers

If you watch or comment on Root Cause videos, YouTube (Google) processes that data under its own terms. The channel's videos are not marked "made for kids", so YouTube's standard features apply. The operator only sees what YouTube Studio shows any channel owner.

7. Your rights (GDPR)

If you are in the EU or EEA, you may ask for access to, correction of, or deletion of any personal data the operator holds about you, and you may complain to a data protection authority. Write to ahseust@gmail.com.

8. Children

The videos are made to be suitable for young viewers, but neither this website nor Root Cause Publisher collects any information from children.

9. Changes

If this policy changes, the new version will be posted here with a new effective date.
